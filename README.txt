CPA Study Room - Samsung TV Browser Edition

FILES
- index.html
- communication-skills.pdf
- law-and-governance.pdf

HOW TO USE
1. Keep all three files in the same folder.
2. For testing on a computer, open index.html in a browser.
3. For use on a Samsung Smart TV, upload the folder to a static web host (or a web server on your local network), then open the index.html URL in the TV browser.
4. Choose a study text from the left-side library. Use the TV remote's arrow keys and OK/Enter button to navigate.

IMPORTANT COMPATIBILITY NOTE
Samsung TV browser PDF support varies by TV model and firmware. This page uses a standard embedded PDF object with a direct-open fallback. If the TV browser does not render the embedded document, select "Open PDF separately". The page itself does not convert PDFs to images, so text remains searchable where the browser's PDF viewer supports it.

No external libraries, fonts, or services are required. The PDF paths are relative, so the files must stay alongside index.html.
